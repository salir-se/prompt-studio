# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who participates in issues, pull requests, and discussions is expected to
follow it.

## Reporting

Report unacceptable behavior privately to the maintainers through
[GitHub private vulnerability reporting](https://github.com/salir-se/prompt-studio/security/advisories/new)
(choose it even for conduct reports; the report stays private), or by contacting a maintainer directly.
Maintainers will review every report, keep the reporter's identity confidential, and respond with the
enforcement steps described in the Contributor Covenant.
